# MPP Programme Explorer — Refactoring Plan

This is a solid, working single-file tool. The issue is that it mixes **five distinct concerns** in one module:

1. **Java/JVM bridge** (JPype + MPXJ loading)
2. **Domain model** (tasks, resources, dependencies, calendars — currently raw Java objects everywhere)
3. **Extraction / analysis** (walking the project, computing summaries)
4. **GUI** (Tkinter widgets, tab construction, event wiring)
5. **Reporting / export** (CSV writers)

For your long-term goal (graph-data overlay into an architecture modelling tool), the **most important refactor is separating (2) and (3) from the GUI entirely** — because your graph overlay will consume the same domain model the GUI does, without any Tkinter involvement.

Below is a proposed structure, then the code for the key new modules, then a list of features worth adding.

## 2. Core: JVM + session (extracted)

**`core/safe.py`** — unchanged helpers, just moved:

```python
from __future__ import annotations

def safe_call(obj, method_name, default=""):
    if obj is None:
        return default
    try:
        value = getattr(obj, method_name)()
        return default if value is None else value
    except Exception:
        return default


def as_text(value) -> str:
    if value is None:
        return ""
    try:
        return str(value)
    except Exception:
        return ""


def as_bool_text(value) -> str:
    if value is None or value == "":
        return ""
    text = str(value).strip().lower()
    if text == "true":
        return "Yes"
    if text == "false":
        return "No"
    return str(value)


def collection_items(collection) -> list:
    if collection is None:
        return []
    try:
        return list(collection)
    except Exception:
        return []
```

**`core/jvm.py`** — isolate JPype completely:

```python
from __future__ import annotations

from pathlib import Path
import jpype

from .errors import flatten_exception


class JvmSession:
    """Owns the JPype JVM and the MPXJ reader class."""

    def __init__(self, jar_path: Path):
        self.jar_path = Path(jar_path)
        self.reader_class = None
        self.java_version = ""

    def start(self) -> None:
        if not self.jar_path.exists():
            raise FileNotFoundError(
                f"Cannot find {self.jar_path.name}.\n"
                f"Expected location:\n{self.jar_path}"
            )

        if not jpype.isJVMStarted():
            jpype.startJVM(classpath=[str(self.jar_path)])

        self.reader_class = jpype.JClass(
            "net.sf.mpxj.reader.UniversalProjectReader"
        )

        system_class = jpype.JClass("java.lang.System")
        self.java_version = str(system_class.getProperty("java.version"))

    def is_ready(self) -> bool:
        return self.reader_class is not None

    def read(self, filename: str):
        if self.reader_class is None:
            raise RuntimeError("MPXJ reader is not initialised.")
        reader = self.reader_class()
        return reader.read(str(filename))

    def shutdown(self) -> None:
        try:
            if jpype.isJVMStarted():
                jpype.shutdownJVM()
        except Exception:
            pass


def jclass(name: str):
    """Convenience wrapper so panels don't import jpype directly."""
    return jpype.JClass(name)
```

```python
class ProjectLoadError(RuntimeError):
    pass


def flatten_exception(exception) -> str:
    lines = [str(exception)]
    try:
        java_value = getattr(exception, "__javavalue__", None)
        if java_value:
            lines.append(str(java_value))
    except Exception:
        pass
    return "\n".join(line for line in lines if line)
```

## 3. Domain model — the big win for your graph overlay

```python
from dataclasses import dataclass, field
from .task import Task
from .resource import Resource
from .assignment import Assignment
from .dependency import Dependency
from .calendar import Calendar


@dataclass
class Project:
    source_path: str = ""
    title: str = ""

    tasks: list[Task] = field(default_factory=list)
    resources: list[Resource] = field(default_factory=list)
    assignments: list[Assignment] = field(default_factory=list)
    dependencies: list[Dependency] = field(default_factory=list)
    calendars: list[Calendar] = field(default_factory=list)
    properties: dict[str, str] = field(default_factory=dict)
    import_messages: list[str] = field(default_factory=list)

    # indexes (built once by extractor)
    tasks_by_unique_id: dict[int, Task] = field(default_factory=dict)
    resources_by_unique_id: dict[int, Resource] = field(default_factory=dict)

    def index(self) -> None:
        self.tasks_by_unique_id = {t.unique_id: t for t in self.tasks}
        self.resources_by_unique_id = {r.unique_id: r for r in self.resources}

    def children_of(self, task: Task) -> list[Task]:
        return [self.tasks_by_unique_id[c] for c in task.child_unique_ids
                if c in self.tasks_by_unique_id]

    def root_tasks(self) -> list[Task]:
        return [t for t in self.tasks if t.parent_unique_id is None]
```

**`model/extractor.py`** — the only module that knows about MPXJ Java objects:

```python
from __future__ import annotations

from core.safe import safe_call, as_text, collection_items
from .project import Project
from .task import Task
from .resource import Resource
from .assignment import Assignment
from .dependency import Dependency
from .calendar import Calendar


class ProjectExtractor:
    """Converts an MPXJ Java project into a pure-Python Project model."""

    def extract(self, java_project, source_path: str = "") -> Project:
        project = Project(source_path=source_path)
        project.title = as_text(
            safe_call(safe_call(java_project, "getProjectProperties", None),
                      "getProjectTitle")
        )

        project.tasks       = self._extract_tasks(java_project)
        project.resources   = self._extract_resources(java_project)
        project.calendars   = self._extract_calendars(java_project)
        project.dependencies = self._extract_dependencies(java_project)
        project.assignments = self._extract_assignments(java_project)
        project.properties  = self._extract_properties(java_project)
        project.import_messages = self._extract_messages(java_project)

        project.index()
        self._link_relationships(project, java_project)
        return project

    # ---- tasks ----
    def _extract_tasks(self, java_project) -> list[Task]:
        tasks = collection_items(
            safe_call(java_project, "getTasks", None)
            or safe_call(java_project, "getAllTasks", None)
        )
        result = []
        for t in tasks:
            result.append(Task(
                unique_id=int(safe_call(t, "getUniqueID", 0) or 0),
                id=safe_call(t, "getID", None),
                name=as_text(safe_call(t, "getName")),
                wbs=as_text(safe_call(t, "getWBS")),
                outline_level=int(safe_call(t, "getOutlineLevel", 0) or 0),
                outline_number=as_text(safe_call(t, "getOutlineNumber")),
                start=as_text(safe_call(t, "getStart")),
                finish=as_text(safe_call(t, "getFinish")),
                duration=as_text(safe_call(t, "getDuration")),
                actual_start=as_text(safe_call(t, "getActualStart")),
                actual_finish=as_text(safe_call(t, "getActualFinish")),
                baseline_start=as_text(safe_call(t, "getBaselineStart")),
                baseline_finish=as_text(safe_call(t, "getBaselineFinish")),
                percent_complete=as_text(safe_call(t, "getPercentageComplete")),
                percent_work_complete=as_text(
                    safe_call(t, "getPercentageWorkComplete")),
                is_summary=self._bool(safe_call(t, "getSummary")),
                is_milestone=self._bool(safe_call(t, "getMilestone")),
                is_critical=self._bool(safe_call(t, "getCritical")),
                is_active=self._bool(safe_call(t, "getActive"), default=True),
                cost=as_text(safe_call(t, "getCost")),
                actual_cost=as_text(safe_call(t, "getActualCost")),
                remaining_cost=as_text(safe_call(t, "getRemainingCost")),
                work=as_text(safe_call(t, "getWork")),
                actual_work=as_text(safe_call(t, "getActualWork")),
                resource_names=as_text(safe_call(t, "getResourceNames")),
                notes=as_text(safe_call(t, "getNotes")),
                parent_unique_id=self._parent_id(t),
            ))
        return result

    def _parent_id(self, java_task):
        parent = safe_call(java_task, "getParentTask", None)
        if parent is None:
            return None
        return int(safe_call(parent, "getUniqueID", 0) or 0) or None

    def _link_relationships(self, project: Project, java_project) -> None:
        # rebuild parent/child pointers and predecessor/successor ids
        for t in project.tasks:
            if t.parent_unique_id is not None:
                parent = project.tasks_by_unique_id.get(t.parent_unique_id)
                if parent and t.unique_id not in parent.child_unique_ids:
                    parent.child_unique_ids.append(t.unique_id)

        # dependencies
        for dep in project.dependencies:
            p = project.tasks_by_unique_id.get(dep.predecessor_unique_id)
            s = project.tasks_by_unique_id.get(dep.successor_unique_id)
            if p and dep.successor_unique_id not in p.successor_ids:
                p.successor_ids.append(dep.successor_unique_id)
            if s and dep.predecessor_unique_id not in s.predecessor_ids:
                s.predecessor_ids.append(dep.predecessor_unique_id)

    # ---- resources / calendars / assignments / deps ----
    # (Implement analogously — I'll show one for brevity.)
    def _extract_resources(self, java_project) -> list[Resource]:
        result = []
        for r in collection_items(safe_call(java_project, "getResources", None)):
            name = as_text(safe_call(r, "getName"))
            if not name and not as_text(safe_call(r, "getID")):
                continue
            calendar = safe_call(r, "getCalendar", None)
            result.append(Resource(
                unique_id=int(safe_call(r, "getUniqueID", 0) or 0),
                id=as_text(safe_call(r, "getID")),
                name=name,
                initials=as_text(safe_call(r, "getInitials")),
                resource_type=as_text(safe_call(r, "getType")),
                email=as_text(safe_call(r, "getEmailAddress")),
                group=as_text(safe_call(r, "getGroup")),
                max_units=as_text(safe_call(r, "getMaxUnits")),
                standard_rate=as_text(safe_call(r, "getStandardRate")),
                overtime_rate=as_text(safe_call(r, "getOvertimeRate")),
                cost_per_use=as_text(safe_call(r, "getCostPerUse")),
                calendar_name=as_text(safe_call(calendar, "getName")),
                work=as_text(safe_call(r, "getWork")),
                actual_work=as_text(safe_call(r, "getActualWork")),
                remaining_work=as_text(safe_call(r, "getRemainingWork")),
                cost=as_text(safe_call(r, "getCost")),
                actual_cost=as_text(safe_call(r, "getActualCost")),
                remaining_cost=as_text(safe_call(r, "getRemainingCost")),
            ))
        return result

    def _extract_dependencies(self, java_project) -> list[Dependency]:
        deps = []
        tasks = collection_items(
            safe_call(java_project, "getTasks", None)
            or safe_call(java_project, "getAllTasks", None)
        )
        for successor in tasks:
            succ_uid = int(safe_call(successor, "getUniqueID", 0) or 0)
            for rel in collection_items(safe_call(successor, "getPredecessors", None)):
                pred = self._relation_task(rel, "predecessor")
                pred_uid = int(safe_call(pred, "getUniqueID", 0) or 0)
                if pred_uid == 0 or succ_uid == 0:
                    continue
                lag = safe_call(rel, "getLag", None)
                if lag is None:
                    lag = safe_call(rel, "getDuration", "")
                deps.append(Dependency(
                    predecessor_unique_id=pred_uid,
                    successor_unique_id=succ_uid,
                    relation_type=as_text(safe_call(rel, "getType")),
                    lag=as_text(lag),
                ))
        return deps

    def _relation_task(self, relation, direction: str):
        methods = (["getTargetTask", "getPredecessorTask", "getSourceTask"]
                   if direction == "predecessor"
                   else ["getTargetTask", "getSuccessorTask", "getSourceTask"])
        for m in methods:
            v = safe_call(relation, m, None)
            if v is not None:
                return v
        return None

    def _extract_calendars(self, java_project) -> list[Calendar]:
        result = []
        for c in collection_items(safe_call(java_project, "getCalendars", None)):
            parent = safe_call(c, "getParent", None)
            result.append(Calendar(
                unique_id=int(safe_call(c, "getUniqueID", 0) or 0),
                name=as_text(safe_call(c, "getName")),
                calendar_type=as_text(safe_call(c, "getType")),
                parent_name=as_text(safe_call(parent, "getName")),
                working_days=self._working_days(c),
            ))
        return result

    def _working_days(self, calendar) -> str:
        import jpype
        names = ["SUNDAY", "MONDAY", "TUESDAY", "WEDNESDAY",
                 "THURSDAY", "FRIDAY", "SATURDAY"]
        days = []
        try:
            day_cls = jpype.JClass("net.sf.mpxj.Day")
        except Exception:
            return ""
        for name in names:
            try:
                dt = calendar.getCalendarDayType(getattr(day_cls, name))
                if "WORKING" in as_text(dt).upper():
                    days.append(name.title())
            except Exception:
                continue
        return ", ".join(days)

    def _extract_assignments(self, java_project) -> list[Assignment]:
        result = []
        tasks = collection_items(
            safe_call(java_project, "getTasks", None)
            or safe_call(java_project, "getAllTasks", None)
        )
        for task in tasks:
            task_uid = int(safe_call(task, "getUniqueID", 0) or 0)
            task_name = as_text(safe_call(task, "getName"))
            for a in collection_items(safe_call(task, "getResourceAssignments", None)):
                r = safe_call(a, "getResource", None)
                result.append(Assignment(
                    task_unique_id=task_uid,
                    task_name=task_name,
                    resource_unique_id=int(safe_call(r, "getUniqueID", 0) or 0),
                    resource_name=as_text(safe_call(r, "getName")),
                    start=as_text(safe_call(a, "getStart")),
                    finish=as_text(safe_call(a, "getFinish")),
                    units=as_text(safe_call(a, "getUnits")),
                    work=as_text(safe_call(a, "getWork")),
                    actual_work=as_text(safe_call(a, "getActualWork")),
                    remaining_work=as_text(safe_call(a, "getRemainingWork")),
                    cost=as_text(safe_call(a, "getCost")),
                    actual_cost=as_text(safe_call(a, "getActualCost")),
                    remaining_cost=as_text(safe_call(a, "getRemainingCost")),
                ))
        return result

    def _extract_properties(self, java_project) -> dict[str, str]:
        props = (safe_call(java_project, "getProjectProperties", None)
                 or safe_call(java_project, "getProperties", None))
        if props is None:
            return {}
        fields = {
            "Project Title": "getProjectTitle",
            "Title": "getTitle",
            "Subject": "getSubject",
            "Author": "getAuthor",
            "Manager": "getManager",
            "Company": "getCompany",
            "Category": "getCategory",
            "Keywords": "getKeywords",
            "Comments": "getComments",
            "Creation Date": "getCreationDate",
            "Last Saved": "getLastSaved",
            "Last Author": "getLastAuthor",
            "Application Version": "getApplicationVersion",
            "File Application": "getFileApplication",
            "File Type": "getFileType",
            "Schedule From": "getScheduleFrom",
            "Project Start Date": "getStartDate",
            "Project Finish Date": "getFinishDate",
            "Status Date": "getStatusDate",
            "Current Date": "getCurrentDate",
            "Minutes Per Day": "getMinutesPerDay",
            "Minutes Per Week": "getMinutesPerWeek",
            "Days Per Month": "getDaysPerMonth",
            "Currency Symbol": "getCurrencySymbol",
            "Default Task Type": "getDefaultTaskType",
        }
        return {label: as_text(safe_call(props, method))
                for label, method in fields.items()}

    def _extract_messages(self, java_project) -> list[str]:
        errors = collection_items(safe_call(java_project, "getIgnoredErrors", None))
        return [as_text(e) for e in errors]

    @staticmethod
    def _bool(value, default=False) -> bool:
        if value is None or value == "":
            return default
        return str(value).strip().lower() == "true"
```

**`analysis/summary.py`**:

```python
from dataclasses import dataclass
from model.project import Project


@dataclass
class ProjectSummary:
    task_count: int = 0
    summary_task_count: int = 0
    milestone_count: int = 0
    critical_task_count: int = 0
    dependency_count: int = 0
    resource_count: int = 0
    assignment_count: int = 0
    earliest_start: str = ""
    latest_finish: str = ""

    def as_line(self) -> str:
        return (
            f"Tasks: {self.task_count:,}    "
            f"Summary tasks: {self.summary_task_count:,}    "
            f"Milestones: {self.milestone_count:,}    "
            f"Critical tasks: {self.critical_task_count:,}    "
            f"Dependencies: {self.dependency_count:,}    "
            f"Resources: {self.resource_count:,}    "
            f"Assignments: {self.assignment_count:,}"
        )


def summarise(project: Project) -> ProjectSummary:
    s = ProjectSummary()
    s.task_count = len(project.tasks)
    s.summary_task_count = sum(1 for t in project.tasks if t.is_summary)
    s.milestone_count = sum(1 for t in project.tasks if t.is_milestone)
    s.critical_task_count = sum(1 for t in project.tasks if t.is_critical)
    s.dependency_count = len(project.dependencies)
    s.resource_count = len(project.resources)
    s.assignment_count = len(project.assignments)

    starts = [t.start for t in project.tasks if t.start]
    finishes = [t.finish for t in project.tasks if t.finish]
    if starts:
        s.earliest_start = min(starts)
    if finishes:
        s.latest_finish = max(finishes)
    return s
```

**`analysis/graph.py`** — the module your architecture overlay will actually consume:

```python
"""
Build a language-neutral node/edge structure from a Project.

Output is deliberately dict-based so it can be dumped to JSON and
consumed by a graph modelling tool (Neo4j, NetworkX, custom overlay).
"""
from __future__ import annotations
from dataclasses import dataclass, field, asdict
from model.project import Project


@dataclass
class GraphNode:
    id: str
    kind: str                       # "task" | "resource" | "milestone"
    label: str
    attributes: dict = field(default_factory=dict)


@dataclass
class GraphEdge:
    source: str
    target: str
    kind: str                       # "depends_on" | "assigned_to" | "child_of"
    attributes: dict = field(default_factory=dict)


@dataclass
class ProjectGraph:
    nodes: list[GraphNode] = field(default_factory=list)
    edges: list[GraphEdge] = field(default_factory=list)

    def to_dict(self) -> dict:
        return {
            "nodes": [asdict(n) for n in self.nodes],
            "edges": [asdict(e) for e in self.edges],
        }


def build_graph(project: Project, *, include_resources: bool = True) -> ProjectGraph:
    g = ProjectGraph()

    for t in project.tasks:
        kind = "milestone" if t.is_milestone else "task"
        g.nodes.append(GraphNode(
            id=f"task:{t.unique_id}",
            kind=kind,
            label=t.name or f"Task {t.unique_id}",
            attributes={
                "wbs": t.wbs,
                "start": t.start,
                "finish": t.finish,
                "duration": t.duration,
                "critical": t.is_critical,
                "summary": t.is_summary,
                "complete": t.percent_complete,
            },
        ))

        if t.parent_unique_id is not None:
            g.edges.append(GraphEdge(
                source=f"task:{t.parent_unique_id}",
                target=f"task:{t.unique_id}",
                kind="child_of",
            ))

    for d in project.dependencies:
        g.edges.append(GraphEdge(
            source=f"task:{d.predecessor_unique_id}",
            target=f"task:{d.successor_unique_id}",
            kind="depends_on",
            attributes={"type": d.relation_type, "lag": d.lag},
        ))

    if include_resources:
        for r in project.resources:
            g.nodes.append(GraphNode(
                id=f"resource:{r.unique_id}",
                kind="resource",
                label=r.name or f"Resource {r.unique_id}",
                attributes={
                    "type": r.resource_type,
                    "email": r.email,
                    "max_units": r.max_units,
                },
            ))
        for a in project.assignments:
            g.edges.append(GraphEdge(
                source=f"task:{a.task_unique_id}",
                target=f"resource:{a.resource_unique_id}",
                kind="assigned_to",
                attributes={"units": a.units, "work": a.work},
            ))

    return g
```

```python
def task_matches(task, needle: str) -> bool:
    needle = needle.strip().lower()
    if not needle:
        return True
    haystack = " ".join([
        task.name, task.wbs, str(task.id or ""), str(task.unique_id)
    ]).lower()
    return needle in haystack
```

```python
from __future__ import annotations
import tkinter as tk
from tkinter import ttk


class Panel(ttk.Frame):
```

**`gui/panels/programme_structure.py`** — this is where the existing big method `_build_programme_tab` + task-detail notebook ends up, but now operating on `Task` dataclasses instead of Java objects:

```python
from tkinter import ttk
from gui.panels.base import Panel
from gui.scrollable_tree import ScrollableTree
from gui.property_grid import PropertyGrid
from gui.task_detail import TaskDetailNotebook


class ProgrammeStructurePanel(Panel):
    title = "Programme Structure"

    def __init__(self, parent, app):
        super().__init__(parent, app)

        paned = ttk.Panedwindow(self, orient="horizontal")
        paned.pack(fill="both", expand=True)

        left = ttk.Frame(paned, padding=4)
        right = ttk.Frame(paned, padding=4)
        paned.add(left, weight=3)
        paned.add(right, weight=2)

        columns = ("ID", "WBS", "Start", "Finish", "Duration",
                   "Complete", "Milestone", "Critical")
        self.tree_frame = ScrollableTree(left, columns, tree_column=True)
        self.tree_frame.pack(fill="both", expand=True)
        self.tree = self.tree_frame.tree
        self.tree.heading("#0", text="Programme / Task")
        self.tree.column("#0", width=440, minwidth=250)

        self.tree.tag_configure("summary", font=("Segoe UI", 9, "bold"))
        self.tree.tag_configure("milestone", foreground="#005A9C")
        self.tree.tag_configure("critical", foreground="#B00020")
        self.tree.tag_configure("inactive", foreground="#777777")

        self.detail = TaskDetailNotebook(right, app)
        self.detail.pack(fill="both", expand=True)

        self._task_by_tree_id = {}
        self.tree.bind("<<TreeviewSelect>>", self._on_select)

    # ------------- lifecycle -------------

    def clear(self):
        self.tree_frame.clear()
        self._task_by_tree_id.clear()
        self.detail.clear()

    def populate(self, project):
        for task in project.root_tasks():
            self._insert(project, "", task)

    def _insert(self, project, parent_id, task):
        tags = []
        if task.is_summary:    tags.append("summary")
        if task.is_milestone:  tags.append("milestone")
        if task.is_critical:   tags.append("critical")
        if not task.is_active: tags.append("inactive")

        tree_id = self.tree.insert(
            parent_id, "end",
            text=task.display_label(),
            values=(
                task.id, task.wbs, task.start, task.finish,
                task.duration, task.percent_complete,
                "Yes" if task.is_milestone else "",
                "Yes" if task.is_critical else "",
            ),
            tags=tuple(tags),
            open=False,
        )
        self._task_by_tree_id[tree_id] = task
        for child in project.children_of(task):
            self._insert(project, tree_id, child)

    def _on_select(self, _event=None):
        sel = self.tree.selection()
        if not sel:
            return
        task = self._task_by_tree_id.get(sel[0])
        if task:
            self.detail.show_task(task, self.app.project)

    # ------------- external API used by Find / Task Register double-click

    def reveal_task(self, unique_id: int) -> bool:
        for tree_id, task in self._task_by_tree_id.items():
            if task.unique_id == unique_id:
                self._open_parents(tree_id)
                self.tree.selection_set(tree_id)
                self.tree.focus(tree_id)
                self.tree.see(tree_id)
                return True
        return False

    def _open_parents(self, tree_id):
        parent = self.tree.parent(tree_id)
        while parent:
            self.tree.item(parent, open=True)
            parent = self.tree.parent(parent)

    def expand_all(self):
        self._set_open("", True)

    def collapse_all(self):
        self._set_open("", False)

    def _set_open(self, parent, state):
        for item in self.tree.get_children(parent):
            self.tree.item(item, open=state)
            self._set_open(item, state)
```

## 7. `app.py` — the new orchestrator (~150 lines)

```python
from __future__ import annotations
import tkinter as tk
from tkinter import filedialog, messagebox
from pathlib import Path

from core.jvm import JvmSession
from core.errors import flatten_exception
from model.extractor import ProjectExtractor

from gui.style import configure_style
from gui.menu import build_menu
from gui.status_bar import StatusBar
from gui.panels.programme_structure import ProgrammeStructurePanel
from gui.panels.task_register import TaskRegisterPanel
from gui.panels.milestones import MilestonesPanel
from gui.panels.dependencies import DependenciesPanel
from gui.panels.resources import ResourcesPanel
from gui.panels.assignments import AssignmentsPanel
from gui.panels.calendars import CalendarsPanel
from gui.panels.project_properties import ProjectPropertiesPanel
from gui.panels.import_messages import ImportMessagesPanel


APP_TITLE = "MPP Programme Explorer"
JAR_NAME = "projectlibre-1.9.8.jar"
SCRIPT_DIR = Path(__file__).resolve().parent
JAR_PATH = SCRIPT_DIR.parent / JAR_NAME   # adjust per your layout


PANEL_CLASSES = [
    ProgrammeStructurePanel,
    TaskRegisterPanel,
    MilestonesPanel,
    DependenciesPanel,
    ResourcesPanel,
    AssignmentsPanel,
    CalendarsPanel,
    ProjectPropertiesPanel,
    ImportMessagesPanel,
]


class Application:
    def __init__(self, root: tk.Tk):
        self.root = root
        self.root.title(APP_TITLE)
        self.root.geometry("1600x920")

        self.jvm = JvmSession(JAR_PATH)
        self.extractor = ProjectExtractor()
        self.project = None
        self.current_file: Path | None = None

        configure_style(self.root)

        self.status = StatusBar(root)
        self.notebook = ttk.Notebook(root)
        self.notebook.pack(fill="both", expand=True, padx=8, pady=5)

        self.panels = []
        for cls in PANEL_CLASSES:
            panel = cls(self.notebook, self)
            self.notebook.add(panel, text=panel.title)
            self.panels.append(panel)

        self.status.pack(fill="x", side="bottom")
        build_menu(root, self)

        root.protocol("WM_DELETE_WINDOW", self.shutdown)
        root.after(50, self.start_jvm)

    # ---- lifecycle ----

    def start_jvm(self):
        try:
            self.jvm.start()
            self.status.set(f"Ready. MPXJ loaded using Java {self.jvm.java_version}")
        except Exception as ex:
            self.status.set("JVM initialisation failed")
            messagebox.showerror("Java / MPXJ error", flatten_exception(ex))

    def open_mpp(self):
        if not self.jvm.is_ready():
            messagebox.showwarning("MPXJ not available",
                                   "The MPXJ reader has not been initialised.")
            return

        filename = filedialog.askopenfilename(
            title="Open Microsoft Project programme",
            filetypes=[("Microsoft Project files", "*.mpp"),
                       ("Microsoft Project templates", "*.mpt"),
                       ("Microsoft Project XML", "*.xml"),
                       ("All files", "*.*")],
        )
        if not filename:
            return

        self.status.set(f"Reading {Path(filename).name}...")
        self.root.update_idletasks()
        try:
            java_project = self.jvm.read(filename)
            if java_project is None:
                raise RuntimeError("MPXJ returned no project.")
            self.project = self.extractor.extract(java_project, filename)
            self.current_file = Path(filename)
            self.root.title(f"{APP_TITLE} - {self.current_file.name}")
            for panel in self.panels:
                panel.on_project_loaded(self.project)
            self.status.set(f"Loaded {self.current_file}")
        except Exception as ex:
            self.project = None
            messagebox.showerror("Could not open programme", flatten_exception(ex))
            self.status.set("Programme load failed")

    def shutdown(self):
        self.jvm.shutdown()
        self.root.destroy()


def main():
    import tkinter as tk
    from tkinter import ttk  # noqa: F401  (needed above)
    root = tk.Tk()
    Application(root)
    root.mainloop()
```

## 8. Features worth adding (roughly in priority order)

These slot cleanly into the architecture above and mostly live in `analysis/` so they serve both GUI and graph overlay:

1. **`analysis/critical_path.py`** — longest path by duration through the dependency DAG; useful because MPP flags criticality but doesn't always expose *why*.
2. **`analysis/health.py`** — quality checks that matter when you're mapping into an architecture model:
   - tasks with no predecessor/successor,
   - orphaned resources (assigned to nothing),
   - tasks with no resource assignment,
   - summary tasks with dates outside children's range,
   - duplicate names.
   Return a list of `Issue(severity, task_uid, message)`.
3. **`analysis/lookahead.py`** — filter tasks by a sliding window (e.g. next 90 days from status date). Almost always what programme managers want.
4. **`reporting/mermaid_export.py`** — emit a Mermaid `flowchart` or `gantt` block. Trivial from `build_graph`, and it's the fastest path to "see the graph."
5. **`reporting/graphml_export.py`** / **`reporting/cypher_export.py`** — direct output for Neo4j / yEd / Gephi, ready for your architecture overlay.
6. **Baseline variance panel** — a tab that lists tasks where `finish` ≠ `baseline_finish`, sorted by slip. Very high value, low cost, and the data is already in `Task`.
7. **Resource heatmap** — days × resources, coloured by allocated units. Fits naturally as a `Panel` subclass.
8. **`analysis/rollup.py`** — compute hierarchical rollups (cost, work, % complete) for summary tasks, since MPP sometimes leaves them blank after edits.
9. **Undo-free "Save filtered view as CSV"** in every panel, replacing the current per-register CSV exports with a generic helper on `Panel` — `export_current_view()`.
10. **Configuration file** (`~/.mpp_explorer.toml`) — remember last-open directory, column widths, window geometry, preferred export format.

## 9. Suggested migration order (so you never break the working tool)

1. Create the package skeleton. Move `ScrollableTree`, `PropertyGrid`, and the `safe_call`/`as_text` helpers into `gui/` and `core/safe.py`. **App still runs.**
2. Add `core/jvm.py` and switch `start_jvm` / `open_mpp` to use it. **App still runs.**
3. Add the domain model + `ProjectExtractor`. Add a single hidden "self-test" that calls it right after load and logs summary counts to the status bar. **App still runs, and you can verify parity with the old code path.**
4. Switch one panel at a time to read from `self.project.tasks` instead of Java objects. Start with the smallest (Project Properties, Import Messages), work up to Programme Structure last. **App still runs after every step.**
5. Introduce the `Panel` base class and move `_build_*_tab` into `gui/panels/*`. **App still runs.**
6. Delete the old `explorer.py` body once nothing references Java objects outside `core/jvm.py` and `model/extractor.py`.
7. Then start adding the features from §8.
